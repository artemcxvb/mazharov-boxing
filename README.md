# Mazharov Boxing

Мобильное веб-приложение для тренера по боксу **Ярослава Мажарова**.

## Возможности

- Управление учениками (группы, вес, поиск)
- Отметка посещаемости на тренировке
- Групповые и индивидуальные тренировки + запись
- Прогресс (навыки + динамика веса)
- Платежи и задолженности
- Мультиязычность: Русский / Polski / Deutsch / English

## Запуск

Открой `index.html` в браузере (лучше на телефоне или в режиме мобильного устройства).

Это PWA-готовая концепция. Для полноценного нативного приложения (iOS/Android) можно обернуть в Capacitor или React Native.

## Стек

- Чистый HTML + CSS + JavaScript
- Адаптивный мобильный интерфейс
- Тёмная тема в стиле премиум-приложений
