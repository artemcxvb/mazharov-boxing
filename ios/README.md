# Mazharov Boxing — iOS / Android

Нативное мобильное приложение для тренера по боксу **Ярослава Мажарова**.

Сделано на **Expo (React Native)** — можно собрать под iOS и Android.

## Как запустить на iOS

```bash
npm install
npx expo start
```

Отсканируй QR-код приложением Expo Go на iPhone.

Для сборки нативного приложения:
```bash
npx expo prebuild
npx expo run:ios
```
